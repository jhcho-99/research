# 작업 인수인계 문서 (다른 컴퓨터·다른 AI에서 이어서 작업용)

> 이 저장소는 **공개(public)** 입니다. 이메일, 토큰, 비밀번호 같은 개인정보는 여기에 적지 마세요.

## 1. 프로젝트 개요

- 이름: 해외주식 분석자료 (지원자 조준현)
- 목적: 해외주식 기업 분석 자료를 모아 보여주는 정적 웹사이트. 지원용 포트폴리오로 쓸 예정.
- 이력서·자소서는 이 사이트에 넣지 않음 (별도 양식으로 제출).
- 저장소: https://github.com/jhcho-99/research
- 배포 주소: https://jhcho-99.github.io/research/
- 배포 방식: `main` 브랜치에 push하면 GitHub Actions(`.github/workflows/pages.yml`)가 `site/` 폴더를 GitHub Pages로 자동 배포 (약 20~40초). Pages 설정은 이미 "GitHub Actions" 소스로 켜져 있음.
- 빌드 단계 없음. 순수 HTML/CSS/JS (프레임워크·npm 의존성 없음).

## 2. 폴더 구조

```
site/                      # 공개되는 폴더
  index.html               # 목록 페이지 (검색, 시장 필터, 표 형태 목록)
  report.html              # 상세 페이지 (?id=... 로 reports.json의 id 지정)
  assets/style.css         # 전체 디자인
  assets/app.js            # 목록 렌더링·검색·필터
  assets/report.js         # 상세 렌더링 (제목 영역 + 본문 + Key Data 박스)
  assets/md.js             # 자체 마크다운 렌더러 (HTML 이스케이프 후 변환)
  data/reports.json        # 분석 자료 목록(메타데이터)
  reports/*.md             # 분석 자료 본문 (마크다운)
  .nojekyll
serve.js                   # 로컬 미리보기 서버 (node serve.js 8770)
docs/HANDOFF.md            # 이 문서
```

## 3. 새 분석 자료 추가 방법

1. `site/reports/template.md`를 복사해 `site/reports/<id>.md`로 저장하고 채웁니다. `<id>`는 영문·숫자·`-`·`_`만 가능 (예: `nvda-2026q3`).
2. `site/data/reports.json`에 항목을 추가합니다.

```json
{
  "id": "nvda-2026q3",
  "ticker": "NVDA",
  "name": "NVIDIA",
  "market": "미국",
  "sector": "반도체",
  "date": "2026-10-20",
  "title": "분석 제목",
  "summary": "목록에 보일 한두 줄 요약",
  "tags": ["AI", "반도체"],
  "keyData": {
    "투자의견": "BUY",
    "목표주가": "$000",
    "현재주가": "$000",
    "상승여력": "+00%",
    "시가총액": "$00B"
  }
}
```

3. 커밋하고 push하면 자동 배포됩니다.

- `keyData`의 키는 자유롭게 추가·삭제 가능. 단 목록 표에는 `투자의견`, `목표주가` 키만 표시되고, 상세의 Key Data 박스에서는 이 두 항목이 오렌지색으로 강조됨.
- 마크다운 지원: `#`~`####`, 문단, 목록(`-`, `1.`), 인용(`>`), 구분선(`---`), 코드블록, 표, **굵게**, *기울임*, `코드`, 링크(http/https만).
- 현재 `reports.json`에는 가상 기업 샘플(`sample-growth`)과 빈 양식(`template`)이 들어 있음. **샘플의 숫자는 모두 가짜**이므로 실제 자료를 올릴 때 샘플은 삭제.

## 4. 로컬 미리보기

```bash
node serve.js 8770
# http://localhost:8770
```

`fetch`를 쓰기 때문에 `index.html`을 파일로 직접 열면 목록이 안 보입니다. 반드시 서버로 여세요. (Python이 있으면 `python -m http.server 8770 --directory site`도 가능)

## 5. 디자인 규칙

국내 증권사 포털 사이트 느낌의 라이트 테마. **특정 회사 이름·로고는 사용하지 않기로 함.**

- 폰트: 나눔고딕 (Google Fonts, Nanum Gothic 400/700/800). 무료 폰트.
- 색상 토큰 (`site/assets/style.css`의 `:root`):

| 토큰 | 값 | 용도 |
|---|---|---|
| `--brand` | `#1f438c` | 메인 네이비 (메뉴 바, 표 상단선, 선택된 필터) |
| `--blue` | `#115bc0` | 링크, 포커스 |
| `--navy` | `#263340` | 제목·강조 텍스트 |
| `--text` | `#3d3d3d` | 본문 |
| `--muted` | `#6d6d6d` | 보조 텍스트 |
| `--head-bg` | `#e7edf5` | 표 머리·박스 배경 |
| `--accent` | `#fc641c` | 오렌지 포인트 (투자의견, 목표주가, 구분선) |

- 헤더: 흰 로고 영역(제목) + 네이비 메뉴 바(부제).
- 목록은 게시판형 표, 모바일(720px 이하)에서는 카드형으로 전환.
- 다크모드는 지원하지 않음.

## 6. 현재 화면 문구

- 상단 큰 제목: `해외주식 분석자료`
- 네이비 메뉴 바: `지원자 조준현`
- 메인 페이지 탭 제목: `해외주식 분석자료 · 지원자 조준현`
- 하단: 투자 유의사항 문구 (지우지 말 것). 자료는 개인 기록용이며 투자 권유가 아님.

## 7. 작업 이력 (요약)

1. 이력서 사이트로 시작했으나, 이력서·자소서는 별도 양식으로 제출하기로 해서 **해외주식 분석자료 전용 사이트 템플릿**으로 방향 변경.
2. 새 GitHub 계정(`jhcho-99`)으로 공개 저장소 `research` 생성, Pages(GitHub Actions) 배포 설정.
3. 증권사 리포트풍 디자인 적용: 목록 표, 상세의 Key Data 박스, 재무·밸류에이션 표 스타일.
4. 모바일에서 Key Data 박스가 화면 밖으로 밀리던 문제 수정 (그리드 `minmax(0, 1fr)`).
5. 폰트를 나눔고딕으로, 색상을 네이비·블루그레이·오렌지 계열로 교체하고 헤더를 흰 영역 + 네이비 메뉴 바로 변경. 다크모드 제거.
6. 문구 변경: 상단 제목 `해외주식 분석자료`, 메뉴 바 `지원자 조준현`.

## 8. 남은 일 / 참고

- 실제 분석 자료 작성·추가 (현재는 가상 샘플과 빈 양식뿐).
- 샘플 항목(`sample-growth`) 삭제.
- 목록 페이지의 실제 화면은 작업 환경 문제로 스크린샷 확인을 못 했음. 데스크톱·모바일에서 직접 보고 어색한 부분 조정 필요.
- 차트(주가, 매출 추이 등)는 아직 없음. 추가하려면 외부 라이브러리 없이 SVG로 그리거나, 이미지를 `site/reports/` 아래에 두고 마크다운에 넣는 방식 검토 (현재 마크다운 렌더러는 이미지 문법을 지원하지 않음).
- 투자 관련 숫자는 반드시 공시(SEC EDGAR 등) 원문으로 확인하고 출처를 적을 것.

## 9. 다른 컴퓨터에서 이어서 작업하기

```bash
git clone https://github.com/jhcho-99/research.git
cd research
node serve.js 8770        # 미리보기
# 수정 후
git add -A
git commit -m "내용"
git push                  # push하면 자동 배포
```

push하려면 jhcho-99 계정으로 GitHub 로그인(또는 토큰)이 필요합니다. 로그인은 사용자가 직접 하세요.

docs/HANDOFF.md를 먼저 읽고, 거기 적힌 폴더 구조와 디자인 규칙(색상 토큰, 나눔고딕, 특정 회사 이름·로고 금지)을 지켜서 작업해줘.
